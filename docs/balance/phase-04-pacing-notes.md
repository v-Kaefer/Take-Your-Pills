## Phase 04 pacing notes

### Base pace curve
- `0` to `7,999` score: `220` base scroll speed
- `8,000` to `19,999` score: `235` base scroll speed
- `20,000` to `31,999` score: `255` base scroll speed
- `32,000+` score: `270` base scroll speed

### Boost tuning
- Speed-up tiers: `1.35x`, then `1.60x`
- Speed-down tiers: `0.85x`, then `0.70x`
- Speed-up duration stays at `8.0s` with the existing stacked extension

### Expected feel
- The opening run stays readable while the laboratory scenario teaches the lanes.
- Mid-run adds pressure before the city transition without reproducing late-run speed too early.
- Post-transition speed rises through base pacing instead of harsher boost penalties.
