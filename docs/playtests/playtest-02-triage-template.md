## Severity guide
- `critical`: blocks the run, corrupts save/state, or breaks the presentation build.
- `high`: strongly damages readability, fairness, or control understanding.
- `medium`: noticeable issue with workaround; should be fixed if capacity allows.
- `low`: polish-only issue that can be documented if not fixed now.

## Action guide
- `fix now`: required before the final delivery build.
- `defer`: document and move to a later milestone or post-delivery list.
- `accept`: known issue accepted for the delivery build with explicit rationale.
